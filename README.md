# KS Connections

Premium matrimonial consultancy website built with Python and Streamlit for Indian and international families.

## Features
- Responsive landing page
- Illustrative world connections map (not real client data)
- About and services
- Consent-first WhatsApp enquiry form with no server-side storage
- Fees and contact page; no payment processing

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy
Use Streamlit Community Cloud: select `DragonFlash07/KS-Connections`, branch `main`, entrypoint `app.py`.

## Before launch
Verify public contact details, fee terms, business claims, privacy notice, and any payment instructions. Never commit client information, credentials, or payment secrets. Visitors must explicitly send their WhatsApp enquiry.
